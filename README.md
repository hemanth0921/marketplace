# Multi-Vendor Online Marketplace

A complete Multi-Vendor Online Marketplace built using FastAPI, PostgreSQL, SQLAlchemy, Jinja2, HTML, CSS, and JavaScript.

## Features

### User Module
- User Registration
- User Login
- Profile Management

### Vendor Module
- Vendor Registration
- Vendor Dashboard
- Vendor Product Management

### Product Module
- Add Product
- Update Product
- Delete Product
- Product Listing

### Shopping Module
- Cart Management
- Wishlist Management

### Order Module
- Place Order
- Order Tracking
- Order History

### Payment Module
- Payment Processing
- Payment Status

### Review Module
- Product Reviews
- Product Ratings

### Invoice Module
- Invoice Generation

### Admin Module
- Admin Dashboard
- Analytics Dashboard

## Technology Stack

### Backend
- Python
- FastAPI
- SQLAlchemy
- PostgreSQL

### Frontend
- HTML5
- CSS3
- JavaScript
- Jinja2 Templates
